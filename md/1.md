# 0.框架

前端：HTML5+CSS3+JavaScript

后端：Django

# 1.开发环境要求

1.合适的代码编辑器

2.conda环境

3.执行 conda env create -f environment.yml 即可开发/或自行根据需求安装

# 2.开发时在 终端 或 cmd 将路径导航到根目录（含manage.py）执行

## 方法一（推荐）：

python manage.py runserver --settings=epms_backend.settings.dev

## 方法二：

export DJANGO_SETTINGS_MODULE=epms_backend.settings.dev

python manage.py runserver

#### 启动后，访问 http://127.0.0.1:8000 即可看到登陆页面

### 初始登陆

python manage.py migrate --settings=epms_backend.settings.dev

python manage.py createsuperuser --settings=epms_backend.settings.dev
